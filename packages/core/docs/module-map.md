# The core module map

Moved from the core CLAUDE.md, which points here.

One line each, no signatures — the docstring at the top of each module is the reference; this is the
index that tells you which one to open.

| Module | What it owns |
|---|---|
| `home` | The one resolver for the per-user cherrypick home; every path derives from it. Also `heartbeat_path()` (and `beat()`, the one best-effort touch every resident loop makes at the top of a tick; readers use the mtime only) and `halt_flag_path()` — the suite's live kill switch, written by the orchestrator and polled by every live loop, none of which may import each other. |
| `db` | SQLite connection mechanics + additive migrations, including the shared read-only opener. |
| `logs` | One line format for every module log. |
| `jsonio` | `write_json_atomic`: the one write-then-rename for JSON artifacts a reader must never see half-written (advice, stream requests, regime cuts, market regime, the advisor pack, the review fact set, and every module and script artifact that used to carry its own copy). `indent`/`default` are its only knobs because they are the only differences that change the bytes; a writer with `separators` (technicals' charts and watchlist, the IV-rank file) or plain text keeps its own. The replace is retried on a Windows PermissionError (`replace_with_retry`), the fault that killed the supervisor seven times. |
| `events` | Scheduled market releases for a session (`day_events`), from the calendar store `scripts/fetch_market_files.py` writes (BEA; Census, the source for its own releases; Michigan's next-release note, the only source for the preliminary sentiment reading; FRED and its never-dropping `fred_history.json`) plus `calendar`'s FOMC days and rule-computed events (ISM, Conference Board, FOMC minutes, options expiry). A day is `known` only when every source can speak for it, so a missing FRED key reads unknown, never quiet. `phase` is the pure after/before/none/unknown read flies tags entries with. Holds the BEA parser overview shares. Local files only, no network. |
| `calendar` | The suite's single source of trading days, holidays and early closes (`session_close_hhmm`: 13:00 on July 3, the day after Thanksgiving and Christmas Eve when each trades, else 16:00). |
| `fees` | The tastytrade cost model. Every "net" figure in the suite goes through it. Also `broker_fee_total`, the one reading of a broker transaction row's fees that the live fee reconcilers share. |
| `auth` | Keyring credentials + a lazy OAuth session, parameterized per consumer. `CredentialStore.designated_account()` is the one reading of the live account (unset and unreadable are both None). The session factory stamps `User-Agent: cherrypick/<version>` on the HTTP client every token mint and refresh uses, as tastytrade requires. |
| `broker` | Account resolution, option-chain helpers, and the live write path with its governor. `place_order` and `replace_order` share one `_preflight_then_submit` path (governor included); `tests/test_broker.py` scans every package for a `dry_run=False` outside this module. `serialize` is the one SDK-object flattener and the seam's default. `broker.cli` holds the read-only CLI verbs the `tt.py` (meic, earnings) and `broker_cli.py` (bwb, flies) seams share; no path to `place_order`. |
| `excursions` | One closed position's mark path and its best and worst point, on the basis its module records: built from legs for bwb/calendars/pmcc/curve (gross at mid; the endpoint must equal the recorded gross, assignments included; a tick with a leg or held shares unpriced is refused), recorded for earnings (gross) and flies live (net of fees). Flies paper and MEIC (no marks of their own) are priced from the SPX 0DTE quote history from 2026-10-13, gross at mid, endpoints reconciled (557/557, 3,226/3,226); recorded marks always win. Contango and bwb_roll keep no path and say so. CLI `python -m cherrypick.core.excursions read --db --schema --position-id`. |
| `trace` | One closed position's entry and management trace. Entry: the attempts since the arm's previous fill, folded into runs of one outcome, and the filled attempt -- linked where the module links it (flies, MEIC), else matched by session, arm, symbol and time (bwb, calendars, pmcc, curve; every match carries its position's strikes); earnings' screening review; flies live's order trail. Management: the position's events folded into runs, an executed event always alone. A part a module does not record says why. CLI `python -m cherrypick.core.trace read --db --schema --position-id`. |
| `portfolio` | One arm per module held together (strategy-analysis Phase 5): correlation two ways (zero-filled inside both arms' spans; only periods both closed), effective arms ((Σσ / σ of the sum)², over arms with at least `min_periods` since their first close), drawdown benefit of combining, worst periods with arms lost, contributions. Daily or weekly; `equal_risk` (default, each arm scaled to the median arm's spread) or `booked`. CLI `python -m cherrypick.core.portfolio read --manifest JSON --start [--end --period --weights]`, each arm read as the metrics CLI reads it. |
| `execution` | The one live broker ADAPTER and the fill primitives every live loop shares: `Broker` holds one session/account on one process-wide event loop and re-checks the module's injected `live_gates` on every live submit, failing closed; an unset or unreadable designated account refuses (`AccountNotDesignated`) rather than reach `core.broker.resolve_account`'s first-account fallback, and the designation is re-read every call; `order_id_of`/`fill_state` read a placement result and a status row; `orphans` is broker truth against ledger belief; `watch` is the cache-gated fill-watch loop. **Every live submission carries an `external_identifier`, and an uncertain outcome is recovered by it** — the broker does not deduplicate retries, so after a raised submit `Broker.place` reads `broker.orders_today` (terminal orders included) and returns a found order as `recovered: True` rather than a failure a caller would retry into a duplicate. **Absent and unreadable are different answers**: if that read-back fails the outcome is `uncertain: True` and the adapter HOLDS, refusing every later live submission until a read succeeds; an order found placed but recorded nowhere is named and refused until `acknowledge()`. A dry run is never held. The meic and earnings CLIs, which call the seam directly, do the same recovery (tastytrade's idempotency-and-retries guide). Cancel-and-replace re-fetches the order and branches on its status, and never places a second order over one it could not cancel. Modules keep their spec builders, gates, ledgers and loops. The desk is deliberately not built on it; flies' burst watcher and the orchestrator's desk notifier keep their own fill-watch, and `watch` exists so the next module copies neither. Fenced off from the advisor beside `broker`. |
| `risk` | Account-level risk primitives. Fail-closed and opt-in. |
| `livepositions` | Pure netting of the broker's `get_positions` rows against each live module's expected legs, keyed `(underlying, expiry, right, strike)`: what the orchestrator's `live-positions` verdicts compare. Also `cross_module_conflict`: each live loop publishes its held and working legs to `state/live_open_legs/<module>.json`, and an entry opposite another loop's netted leg is refused, since the broker nets one account (a leg it cannot read is a conflict). Talks to no broker and opens no ledger. |
| `live` | The per-day arm record and dead-man's switch a live loop runs under: the filename convention the supervisor mirrors, the record's contents, the two disarm reasons, the supervisor-heartbeat read, and the rule that under a supervisor arming is a record write and nothing else. Also the quarter-end live rule's one reason string and arm-time warning (`QUARTER_END_REASON`, `quarter_end_warning`). `alerts` is the order-alert inbox and daemon an armed module runs (hoisted from flies 2026-10-15 for MEIC; flies still carries its own copy): nothing depends on it, and the orchestrator's `live-fill-alerts` reads it (`fills_after`). |
| `settlement` | American physical settlement's share arithmetic (calendars/pmcc) and the official index close (`official_index_close`: tastytrade → Yahoo → Barchart, with `OFFICIAL_SOURCES` saying which answers a cash-settled ledger may settle on). `dated_index_close` is a past session's official close from Yahoo's daily bar (source `yahoo_daily`), which the overdue live settlement uses. Also the ex-dividend span checks calendars and pmcc refuse on (`ex_dividend_dates`, `dividend_coverage_ok`, `ex_date_in_span`). |
| `spreadbook` | The ledger writes calendars, pmcc and curve share over their `LedgerStore`: the traded close, share disposal, exit-cost accumulation and finalization (`SpreadBook`), plus the exit spread gate (`exit_spread_blocks`). Entry and `settle_expiring_legs` stay in the modules because they genuinely differ; bwb keeps its own four-leg writer. |
| `entry` | Entry-permission rules MEIC and flies must apply identically: cadence and the leg-sign rule. |
| `structures` | Pure option-structure formulas earnings and calendars must agree on (the straddle-based expected move), and the nickel tick rounding every live order builder uses (`tick_floor`/`tick_ceil`). |
| `streamer` | The generic persistent DXLink streaming engine; `packages/streamer` is the daemon around it. |
| `streamcache` | The shared stream-cache schema and its SQLite helpers — the producer/reader contract. `cache_path(config)` is where every READER finds it (`source.stream_cache_db`, else the canonical home path); the producer and gex resolve their own. Also the one OCC ↔ streamer symbol pair (`occ_to_streamer_symbol`, pinned to the SDK; `streamer_to_occ_symbol`, its round-trip-checked inverse — not the SDK's, which mangles digit roots and two-decimal strikes). |
| `streamrequests` | The subscription registry: how a module declares its symbols, plus the union read the streamer subscribes from and the orchestrator checks staleness against (`union_legs` also tells gex's quote recorder which strikes are held). |
| `dxfeed` | On-demand DXLink event collectors, for a snapshot rather than a stream. |
| `gex` | The GEX engine: a pure function over an option-chain snapshot. Copying it once let the math drift ~75×. One gamma per strike, the OTM side's (`strike_gamma`, from 2026-10-12). |
| `rangefeatures` | The daily range-features study exactly as `docs/range-features.md` declared it: four SPX features against a HAR baseline on ranges at 1, 5 and 7 sessions, one Bonferroni family of twelve, a stationary block bootstrap, a forward check at 60 sessions. `feature_series` must stay truncation-invariant (`test_features_are_truncation_invariant`, guarded by mutant `rangefeatures-lookahead`). A definition changed here is a new declaration, not a fix. Reports only. **Retired 2026-10-03 after run 1: no finding**; the code stays as the record of what was tested. |
| `impliedvar` | Model-free implied variance over a whole strip, Cboe's VIX arithmetic for any expiration (`single_term`, `constant_maturity`, `strip_from_cache`). Reproduces Cboe's published worked example strike by strike. Every result says whether each wing ran dry or was cut off by the cache's strike window — a truncated strip reads low and is a lower bound, never a measurement. Never extrapolates across maturities. `python -m cherrypick.core.impliedvar check` compares against VIX/VIX9D from the same cache, and refuses `not_bracketed` when the cache holds no expiration pair around the target (its usual state today). |
| `profiles` | The named risk-profile registry and merge engine — how a partial override becomes an effective config. |
| `metrics` | The shared calibration metric bundle. Its CLI (`python -m cherrypick.core.metrics read`) groups a stamped advised row under `<tag>@<experiment_id>` — display only; `profile` on the record is untouched. `trades` lists the same records one row each (optionally one tag's), from the same read, so a session's rows sum to `read`'s net for it. |
| `advice` | Bounded, expiring, deterministically-validated parameter advice; see the next section. |
| `regimecuts` | The regime-cuts artifact contract: per book × regime dimension × bucket, era-scoped by a module's `measurement_breaks`. `era_bounds` (latest book-wide break on or before the session starts the era; a later book starts at its own break; future-dated breaks listed and ignored; `partial_session` never bounds), `assemble` (`thin` on every cell under three sessions, deterministic order), `write_artifact` (dated file always, latest copy only for a newer session; `write_json_atomic` is re-exported from `jsonio`). Robustness stamps from the writer's per-session `session_nets` (never published): `fragile` + `robustness` per cell (one session ≥ `CONCENTRATED_SHARE` of flow, or dropping any session flips the sign; seeded session bootstrap), `paired` per dimension (same-session exact sign test — a bucket that wins pooled but not paired is a kind of day, not a kind of entry), `history` from prior snapshots, and a document-level `multiplicity` count. Modules keep their own `by_regime`; readers recompute nothing. Exists because a seven-session cell, and later an eleven-session cell that was half one day, each looked like a finding. |
| `stats` | The one home for comparing an arm with its control, sessions as the unit: per-session values and the paired difference (`fill=None` intersects; `fill=0.0` reads a sat-out session as zero inside a window both ran), seeded session bootstrap (`regimecuts`' draw and index rule, pinned), exact Student's t and the one-sided lower bound (a caller may pass a declared, more conservative critical value), exact sign test, `sessions_needed`/minimum detectable effect, sessions until an interval would exclude zero, Holm and Benjamini–Hochberg, the stationary block resample, and `paired_comparison`, the block every surface shows. `regimecuts`, `rangefeatures`, meic's `session_bootstrap`/`experiment.bootstrap_difference`, flies' `intraday_eval.paired_stats` and technicals' `study.holm` call it. Labels nothing pass or fail. |
| `compare` | Every arm of every module beside its control (`python -m cherrypick.core.compare --json`, the console's `/compare` bridge): per arm trades, sessions, gross/costs/net, win rate, per-session max drawdown, per-trade nets, a session-bootstrap interval on mean session net, and `stats.paired_comparison` against its control on their common sessions (0DTE on the day, multi-day on the `entry_session` both entered; one-side-only sessions counted, never filled). Scope defaults to the module's own era: flies/MEIC by `regimecuts.era_bounds` (arm_added starts an arm), key/value journals bounded by every break except `NON_BOUNDING_KEYS`, pmcc by its era stamp. Advised books pair with their experiment's `base_profile` from advisor.db, read-only. Size-normalised beside the dollars: per arm `net_per_entry` and `net_per_100_risk` (on the ledger record's `capital`, known trades only; none recorded is None, never zero), and per pair the same paired comparison on per-session normalised figures (`per_entry`, `per_100_risk`), because a capped arm beside a 270-entry control reads as a size difference in dollars. Mutants: arm start, pairing key, roster keys, fill, per-entry denominator. |
| `ledgers` | Per-schema readers for every module's ledger — the one home for net, cost, capital and session rules. `concentration` says how much of a module net rests on one arm and whether removing it flips the sign (if so, it measures that arm, not the module). Every closed record carries `experiment_id` (None on older ledgers). |
| `regime` | The one at-or-before, staleness-bounded join against the recorded market-regime series (gex's history DB). Derived ratios are computed at read time, never stored. `markets_at` is the market block for many timestamps over one connection (core.analysis's regime breakdowns). |
| `quotehistory` | The read side of gex's chain quotes, kept every recorder tick (~15 s) (`gex_quote_samples` + `gex_quotes`): `session(symbol, date)` returns each kept sample in a flies snapshot's shape, spot joined at-or-before from `gex_spot_history` within 60 s (`regime`'s rule; unjoinable is `None` with a reason, never a neighbour's). What a replay of an untried rule prices against. `RecordedDay` is what the replays (flies, MEIC) build snapshots from: the samples plus the GEX profile (`profile_surface`, refused past 360 s or under a module's strike minimum), the spot trail's bounds up to an instant, the prior close and the trailing range, loaded once; `leg_symbol` names a recorded leg as the streamer would. Any file in the recorder's schema works, backtest's vendor stores included. |
| `analysis` | What an arm's closed trades say beyond `metrics`: streaks, drawdown episodes, durability without the top winners, the reshuffle stress test, the slippage ladder (`execution_sensitivity`), `buckets` breakdowns, observed peak risk and dated declared allocations (`capital`, `<home>/config/arm_capital.json`), each arm read over its own era (`windows`, `regimecuts`' rule). CLI `python -m cherrypick.core.analysis read`; the console's analysis and risk tabs bridge it. |
| `viz` | A declarative dashboard-section contract plus one generic renderer. |
| `clock` | What "now" means, in Eastern, everywhere. |
| `config` | Reading a module config key that has more than one accepted spelling (`books`/`profiles`, the arm registries). |
| `ledgerstore` | The ledger mechanics calendars and pmcc share: upsert, migrate, telemetry writes, readers. |
| `looplock` | Single-instance guards for the suite's loops: is a process alive, and who holds the lock. |
| `marketregime` | The daily-bar market regime (trend and volatility), derived and never recorded. |
| `openingrange` | The 09:30–10:00 ET opening range, derived and never recorded. |
| `redact` | Account numbers masked to `****1234` before they reach a log. |
| `power` | Is this machine on battery (Windows, Linux, macOS)? A reading that cannot be taken is `known: False`, never "plugged in". |
| `bs` | Black-Scholes-Merton (continuous dividend) price, delta and the vol that prices a mid. A model that bounds or compares, never a tradable price. |
| `valuation` | An unlevered DCF of one company from plain numbers the caller read (fiscal years, market cap, a regression beta, the consensus next-year sales growth, a risk-free rate): one mechanical base case (three-year medians for the margin lines, the five-year revenue CAGR, growth faded to a 2% terminal, the WACC floored at 7%) and a low-high range from a WACC x terminal-growth grid, per share. A history it cannot read, a rate too near the growth, or a cash flow that never turns positive is a `Refusal` with its reason, never a number; a terminal value above 75% of EV is flagged. Banks and REITs are refused by sector before the call. A model estimate of value with tested 2018-26 with no edge; never a ranking. `implied` is the reverse DCF: the margin, and separately the year-one growth, at which the base case reads the price, beside the best of five years. Written for the income lists and the Screeners fair-value tab (technicals) so no second DCF arithmetic appears. |
| `treasury` | Treasury's daily par yield curve: the one parser and reader of `market-files/treasury/<year>.csv` (fetched by `scripts/fetch_market_files.py`), answering strictly before a session; `yield_before(session, "10y")` is the fair-value build's risk-free rate and `curves_before` the overview pack's yields block. Hoisted from overview 2026-10-28. A missing or unparseable file is empty or None, never a guess. |
| `vendor` | The one switch (`market_report.collector`) every vendor-fed job and reader follows. |
