# The console layout before the module frame

A read-only survey of `packages/console/web/src` taken on 2026-09-22, immediately before the
lightbox suite began giving way to the left-rail module frame. It records every section, tab and
card as it stood: the component that renders it, where its data comes from, and — the part worth
keeping — every **console-side classification or threshold**, since those are the judgements a
redesign has to either carry across deliberately or drop deliberately.

It covers all twelve modules, the two shared slides (advisor, performance), the Overview page and
the shell chrome.

This exists so each module's sweep has the thing it is replacing written down. When a module moves
to the frame, its section here stays as-is — this is a snapshot of a date, not a live document,
and it is wrong to update it.

## Shared chrome (all 12 modules)

`LightboxFrame` (`lightbox/LightboxFrame.tsx:15`) is a `createPortal` dialog on `document.body`:

- `lb-head` (`:175`): `<h1>{MODULE_LABEL[module]}</h1>`, then `badge`, `loopPill`,
  `session {session}` (only when non-null, `:179`), `headerControls`, then `lb-nav`: `‹` (`aria-label="previous slide"`), an `lb-count` reading `idx+1 / n · <label>`, `›`, the auto-advance toggle (`aria-label` pause/start, `aria-pressed`, `:191`), `✕` close.
- `lb-rail` (`:205`): one `lb-rail-chip` button per slide, text = `label`, disabled when `available === false`.
- `lb-body` → `lb-slide` keyed on the active id; body stays mounted, scroll resets per slide (`:55`).
- `integrity` is a **footer chip** `measurement integrity ▸/▾` (`:234`) opening an `lb-integrity-drawer`; `chip-warn` when `integrityAttention`, which every module computes as `measurementBreaks.length > 0 || schemaDrift.length > 0`. Drawer auto-closes on slide change (`:151`).
- Keyboard: Esc close; ←/→ prev/next slide **wrapping into the prev/next module**; Home/End; Space toggles auto-advance (8 s); Tab focus trap (`:103–139`).

`Card` (`components/DataTable.tsx:151`) = `section.card` with a collapse caret persisted in `localStorage["cherrypick-console-collapsed-v1"]` per `collapseKey` (`:97–132`), `<h2>` title, optional `controls`, and an `as of HH:MM:SS` ET stamp from `updatedAt`. `DataCard` (`:207`) wraps `Card` with `table-scroll > table.data-table.num-from-N`, skeleton rows while loading, an `empty` row at `rowCount === 0`, optional `footer`.

`PaperLiveBadge` (`components/shell/PaperLiveBadge.tsx:4`) renders `PAPER`/`LIVE`.

`LoopPill` (`components/ScopeBar.tsx:234`): `● loop live` / `◐ loop idle` / `○ no loop data` + age. **Age thresholds `ScopeBar.tsx:243-251`:** `< 90` → `Ns ago`; `< 5400` → `Nm ago`; else `N.Nh ago`. Tone `chip-ok/chip-warn/chip-missing` (`:252`). **Loop state is classified console-side in every manifest:** `lastIteration == null ? "no-data" : ageSeconds < 900 ? "live" : "idle"` (`PmccLightbox.tsx:21-22`, `CurveLightbox.tsx:18-19`, `BwbLightbox.tsx:18-19`, `CalendarsLightbox.tsx:19-20`) — the 900 s window is not a server field.
